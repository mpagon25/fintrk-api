# FinTrk API

Backend service for **FinTrk**, responsible for business logic, data persistence, and financial forecasting.

## Overview

The API powers the FinTrk mobile application by providing a structured and scalable backend architecture for managing personal finance data.

It exposes REST endpoints for financial entities such as income, expenses, recurring transactions, and future cash flow projections.

## Responsibilities

- Manage financial data
- Handle recurring transactions
- Generate cash flow forecasts
- Validate incoming data
- Provide RESTful endpoints for the mobile application

## Planned Tech Stack

- Node.js
- NestJS
- TypeScript
- Prisma ORM
- PostgreSQL

## Project Status

The API is developed in parallel with the mobile application. During the early development phase, the mobile app operates on mocked data until the backend reaches feature parity.
